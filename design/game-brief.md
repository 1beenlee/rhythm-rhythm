# Rhythm Rhythm · Lean Game Brief (CCGS minimal)

- **Pitch:** Three joyful toy-like microgames built around listening before acting; an expandable offline game pack.
- **Audience / feeling:** Beginners can start in a beat, advanced players can master timing and syncopation; playful satisfaction.
- **Core loop:** choose game → hear cue → perform timed input → receive distinct audio/visual grade → review score → retry.
- **Goal / fail state:** reach a high score and combo; misses break combo, but the track always finishes. No hard fail screen.
- **MVP (6):** shared shell / synchronized clock / Beat Factory / Echo Planet / Rhythm Kitchen / safe creation + validation workflow.
- **Out of scope:** online accounts, payments, server, multiplayer, online editor, external IP, 49-agent CCGS adoption.
- **Build order:** timing/audio and one-button Beat Factory first → other mechanisms → extensibility → export and real device QA.
- **Art/audio:** original geometric toys, lavender/aqua/coral/yellow, in-engine procedural synth rhythms; no third-party assets.
- **Reference boundary:** genre principle only; original visuals, music and game interactions.

## Mini-game rules

1. **Beat Factory:** a moving package approaches the stamp; press Space/touch once at each marked beat. Later charts include offbeat packages.
2. **Echo Planet:** hear creature call for four beats; copy its pulses for the next four beats. Six progressive rounds with differing patterns.
3. **Rhythm Kitchen:** ingredients travel along two lanes; press A/L or touch the correct lane; alternating beats and syncopation.
